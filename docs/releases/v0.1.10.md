Fix popup dismissal after selecting a clip.

- With **Keep open on top** off, switching to another app, the desktop or taskbar
  dismisses the popup after selection, search or keyboard use.
- Windows foreground changes now handle dismissal consistently in both tray and
  keyboard mode, rather than relying on a separate framework focus notification.
- Keep-open mode and Clipdeck's own dialogs remain open. Opening from the tray
  still preserves the original paste target until you interact with the popup.

History, settings, clipboard contents and Windows startup preferences are preserved.
No database migration is required.
