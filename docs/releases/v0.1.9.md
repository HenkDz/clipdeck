Fix keyboard shortcuts after selecting a single clip from the tray popup.

- Clicking a row now activates Clipdeck for Ctrl+C, Enter and the other selection shortcuts.
- Ctrl+C copies the selected clip to the Windows clipboard, shows **Copied to clipboard**,
  and updates its copied marker and count. It does not paste or create a duplicate row.
- Multi-selection, double-click paste and the inline paste buttons keep their existing actions.

History, settings and Windows startup preferences are preserved. No database migration is required.
