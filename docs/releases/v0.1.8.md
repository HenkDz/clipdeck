Settings and navigation polish.

- Added **Start with Windows** in Settings. It controls the Windows Startup shortcut,
  including shortcuts created for an existing Clipdeck installation.
- **Back** and **Escape** from Updates return to the screen you opened it from.
- Settings retains its scroll position when you visit Updates.
- Preview, editing and gallery navigation preserve the previous screen and list position.
- Returning from editing shows the saved text, and background previews keep loading
  while another screen is open.
- Release notes stay visible after an update finishes downloading.

History and other settings are preserved. No database migration is required.
