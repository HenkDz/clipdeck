Ctrl+C now gives immediate copy feedback and saves multi-item selections as reusable batches.

- Selected items get the blue copied border and their copy counts increase after
  a successful copy. Paste counts are unchanged.
- Several images/files become one attachment batch at the top of recent history,
  with a thumbnail and file count. Text selections combine with line breaks.
- Repeating the same selection updates its existing batch instead of making duplicates.
- Ctrl/Shift selection activates a tray-opened popup so Ctrl+C reaches Clipdeck.
  Ordinary tray clicks retain the no-focus paste workflow.
- Copy completion, grouped history and member counts are committed together;
  errors appear in the popup.

Pinned rows stay above recent history. Existing history-size and max-clip-size
settings still apply. History schema remains v5; no crate versions changed.
