Paste counts now sit beside their icons, keeping every row action vertically centered.

- Keeps regular and plain paste counters readable without moving the icons upward.
- Fixes a duplicate row-action hover style that triggered a debug-build assertion.
- Includes the signed updater introduced in v0.1.2. Use **Check for updates** in
  the tray menu, download the update, then choose **Update and restart**.

v0.1.1 and earlier need a one-time manual installation of this version. History
and settings stay in `%APPDATA%\Clipdeck`. The application folder must be writable.
Update metadata is signed; the Windows executable still has no Authenticode certificate.
