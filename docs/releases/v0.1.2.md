Clipdeck can now check for and install signed updates from GitHub Releases.

## What's new

- **Check for updates** in the tray menu and Settings, with version, release notes,
  download progress, and **Update and restart**.
- Optional daily background checks, off by default. Update checks contact GitHub;
  clipboard contents stay on your PC.
- Signed update metadata, verified executable checksums and Windows version checks.
- Graceful shutdown, a consistent history backup, executable replacement and startup
  confirmation. A failed startup restores the previous executable and history before
  clipboard capture begins.

## Install this version once

v0.1.1 and earlier have no updater. Quit the old copy from its tray menu, download
`clipdeck-0.1.2-windows-x64.zip`, unzip it anywhere and run `clipdeck.exe`.
Future releases can then be installed inside Clipdeck.

History and settings remain in `%APPDATA%\Clipdeck`. No database migration or Rust
dependency version changes. Windows 10 or 11, 64-bit. The app folder must be writable
for in-place updates.

The executable remains unsigned, so SmartScreen may ask for **More info → Run anyway**.
Signed update metadata is separate from Windows code signing. If Windows reports
`VCRUNTIME140.dll` missing, install the
[Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe).

The ZIP is for manual installation. The versioned EXE, `clipdeck-update.toml` and
its signature are for the updater. SHA-256 checksums are also attached.
